# 잔해의 항로 — 첫 번째 신호 v0.1

SF 아포칼립스 자캐 탐사 게임의 **한 사건 완결형 테스트 에피소드**. AI API, 계정, 유료 서버, 외부 폰트/CDN 요청 없이 실행됩니다. 제작 계획서 전체 MVP나 정식 출시판이 아닙니다.

## 실행

Node.js 20 이상에서 저장소를 내려받고:

```sh
npm start
```

`http://localhost:4173` 접속. 의존성 설치나 빌드 불필요. 같은 Wi-Fi의 모바일에서는 PC 방화벽에서 접근을 허용한 뒤 `http://PC의내부IP:4173`으로 접속합니다. `index.html`을 파일로 직접 열지 말고 HTTP 정적 서버를 사용하세요.

GitHub Pages 사용 시 저장소 **Settings → Pages → Deploy from a branch → main / (root)**로 지정합니다. 정적 파일은 모두 상대 경로입니다. 코드 업로드만으로 Pages가 자동 활성화되지는 않습니다.

## 플레이

1. 이름, 제작 목적, 성격 3개, 가치관, 과거를 선택합니다.
2. 거점에서 제7창고로 출발합니다.
3. 직접 구조 / 드론 지원 / 좌표를 남기고 철수를 선택합니다.
4. 거부했다면 대안을 받아들이거나, 가능한 경우 철수하거나, 확인 후 강제 명령을 사용합니다.
5. 결과 확인 → 거점 귀환 → 하루 종료 → 일기를 읽습니다.
6. 거점 탭에서 JSON 백업 및 복원이 가능합니다.

거부는 희귀한 확률 판정입니다. 첫 플레이에서 반드시 발생하지 않습니다. 성향과 가치관, 침수 경험이 판정에 반영됩니다. 새로고침으로 결과를 다시 추첨하지 않습니다.

## 구현 범위

- 목적 3종, 성격 12종 중 3개, 가치관 4종, 과거 4종
- 6개 성향, 전력·기체 상태·안정도, 침수 기억/공포·죄책감
- 수용, 주저, 거부, 거부 후 대체 행동
- 강제 명령 1회: 확인, 모듈 소모, 안정도 −12, 전용 기억과 회고
- 6개 결과: 직접 구조 성공/코어 회수/실패, 드론 성공/구조 요청, 철수
- 최초 선택·실제 행동·결과·중간 시도·성향 변화 개별 기록
- 결과 사실에 근거한 캐릭터 시점 일기 1회 생성·보존
- 모바일 4탭, IndexedDB 원자적 저장, 오래된 탭의 덮어쓰기 차단
- JSON 검증·복원, 새 게임/복원 시 교체 전 저장 1개 보관 및 복구

## 테스트

```sh
npm test
```

브라우저 E2E는 별도 개발 도구가 필요합니다(플레이어에게는 필요 없음):

```sh
npm install --no-save playwright
npx playwright install chromium
# 다른 터미널에서 npm start 실행 후
node tests/browser.mjs
```

기존 Chromium을 쓰려면 `CHROMIUM_PATH=/path/to/chromium node tests/browser.mjs`.

2026-09-21 검증: 엔진 테스트 **11/11 통과**, 10,000회 시드 시뮬레이션, Chromium E2E **9개 체크 통과**. 상세 내용과 재현 시드는 [테스트 보고서](docs/TEST_REPORT.md) 참조.

## 구조와 추가 제작

| 파일 | 책임 |
|---|---|
| `src/content.js` | 캐릭터 옵션, 선택지, 아이템 설명, 결과, 판정 테이블 |
| `src/engine.js` | 순수 상태 전이, 난수, 충돌/결과 판정, 효과, 기억, 일기, 저장 검증 |
| `src/storage.js` | IndexedDB 트랜잭션과 이전 저장 보관 |
| `src/app.js` / `style.css` | 입력, 화면, 모바일 스타일 |
| `src/contracts.d.ts` | 협업용 상태/명령/결과 타입 계약 |

추가 작업 전에 [콘텐츠 작성 안내](docs/CONTENT_GUIDE.md)와 [결정·제약](docs/DECISIONS.md)을 읽어 주세요.

## 아직 없는 기능 / 알려진 제약

- 장편 메인 스토리, 다지역/다일 탐사, 랜덤 사건 큐, 상점/제작, 관계·동료 시스템 미구현
- 이미지 업로드, 소망·외형 입력, 기억 필터/즐겨찾기, 글자 크기 설정, 음악 미구현
- 기억 억제 칩, 방수제, 스캐너, 다중 믿음 형성/회복·히스테리시스 미구현
- 수리 키트는 엔진에 있으나 정상 첫 에피소드는 건강한 상태로 시작해 실제 사용 기회가 없음
- 목적·과거·가치관의 모든 옵션이 별도 사건을 만들지는 않음. 선택한 옵션은 프로필에 보존
- 저장은 브라우저/주소별로 분리되며 기기 자동 동기화 없음. 시크릿 모드·사이트 데이터 삭제 시 소실 가능
- 완전 오프라인 최초 실행을 위한 서비스 워커 없음. 열린 페이지는 외부 통신 없이 플레이하지만 오프라인 재접속을 보장하지 않음
- 저장 포맷 v1만 지원. 미래 버전과 손상 데이터는 거부하며 임의 복구/덮어쓰기를 하지 않음
- 실제 Android Chrome·삼성 인터넷·iOS Safari 기기 테스트 미실시
- 자동화 환경에 한글 글꼴이 없어 스크린샷 한글이 네모로 표시됨. DOM 텍스트/동작 검증은 통과했지만 한글 글꼴을 포함한 최종 시각 검수는 실제 기기에서 필요

현재 코드가 올라간 것과 사이트가 배포된 것, 자동화 테스트 통과와 실제 모바일 검증은 서로 다른 상태입니다.
