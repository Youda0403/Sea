# 잔해의 항로 — 14일의 신호 v0.2

SF 아포칼립스 자캐 탐사 게임의 첫 완결 회차. AI API, 계정, 유료 서버, 외부 폰트/CDN 요청 없이 작동합니다.

## 실행

Node.js 20 이상에서:

```sh
npm start
```

`http://localhost:4173` 접속. 의존성 설치나 빌드는 필요 없습니다. `index.html`을 파일로 직접 열지 말고 HTTP 정적 서버를 사용하세요.

GitHub Pages에서는 저장소 **Settings → Pages → Deploy from a branch → main / (root)**를 선택합니다.

## 현재 플레이 구조

- 캐릭터 이름, 제작 목적, 성격 3개, 가치관, 과거 설정
- 1~14일차 진행. **매일 최대 네 후보 중 자유 탐사 한 곳을 선택 + 날짜 고정 필수 사건 1개**
- 전체 사건 35개(날짜별 기본 28개 + 자유 탐사·후속 사건 7개), 한 회차에는 28개 사건과 14개 일기, 기본 엔딩 3개 + 준비에 따라 해금되는 엔딩 1개
- 출발 전 베이스에서 수리 키트·충전 셀 사용
- 성격·가치관·기억·안정도에 따른 수용·주저·거부·대체 행동
- 강제 명령 모듈 사용 시 안정도 저하와 별도 기억. 낮아진 안정도는 후속 선택의 갈등에도 영향을 줌
- 결과 화면은 사건 서술에 집중. 처음 선택과 실제 행동은 기록 탭의 접힌 상세 정보에서 확인
- 만난 인물 8명의 조우 기록. 만나기 전에는 잠금 상태
- IndexedDB 자동 저장, JSON 백업/복원, v1 저장 자동 변환
- 같은 캐릭터 설정을 유지한 채 1일차로 돌아가는 테스트용 초기화

## 조작 흐름

`베이스 준비 → 자유 탐사 장소 선택 → 탐사 사건 → 필수 사건 → 귀환 → 일기 → 다음 날`. 14일차 일기를 기록하면 선택한 최종 행동에 따라 엔딩이 열립니다.

거부는 확률 판정이라 매번 발생하지 않습니다. 거부 순간은 전용 화면으로 표시되고, 대체 행동이나 강제 명령을 고를 수 있습니다. 새로고침으로 판정을 다시 뽑지 않습니다.

## 아직 없는 기능과 제약

- 메인 사건은 날짜 고정. 자유 탐사는 해당 날짜의 기본 사건 + 이전에 가지 않은 장소 + 실제 선택으로 열린 후속 사건 중 최대 4개에서 1곳을 선택. 출현 후보는 조건부이나, 아직 무작위 추첨과 여러 번의 자유 탐사는 없음
- 상점, 제작, 장비 내구도, 자유로운 아이템 사용, 복잡한 NPC 관계 미구현. 후속 반응은 우선 류 구조→소금 시장 및 일부 탐사 준비→후반 선택지에 집중
- 조우 기록은 간략 소개만 제공하며 관계도·대화 회상은 없음
- 이미지 업로드, 소망·외형 입력, 기억 필터/즐겨찾기, 글자 크기 설정, 음악 미구현
- 저장은 브라우저/주소별로 분리되며 기기 자동 동기화 없음. 이전 v2 저장은 선택한 자유 탐사 필드가 없어도 기본 일정으로 이어짐
- 오프라인 재접속을 위한 서비스 워커 미구현
- 자동화 환경에 한국어 글꼴이 없어 한글의 최종 시각 검수는 실제 기기에서 필요
- 실제 Android Chrome·삼성 인터넷·iOS Safari 기기 테스트 미실시

코드 업로드, GitHub Pages 배포, 실제 모바일 검증은 각각 별도의 상태입니다.
