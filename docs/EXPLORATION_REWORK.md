# 탐사 개편 v0.3 — 플레이어의 하루를 다시 설계하기

이 문서는 2026-09-21 `feat/meaningful-exploration-v1` 브랜치의 **실제 변경 범위**를 설명한다. 기존 `main`의 14일 루프를 삭제하지 않고, 이야기와 시스템 사이에 최소한의 인과를 연결하는 첫 구조 개선이다. 정식 완성판으로 보지 않는다.

## 플레이 흐름

`베이스(정비/충전) → 자유 탐사 후보 중 **한 곳 직접 선택** → 탐사 결과 → 해당 날짜에 고정된 필수 사건 → 귀환 → 일기 → 다음 날`.

- 당일 기본 탐사 1곳은 항상 후보에 포함한다. 방문하지 않은 과거 지역 및 이전 선택으로 열린 특별 탐사 중 최대 3곳을 추가로 노출한다.
- 특별 탐사 `requiresFlags`, `requiresAnyFlags`, `excludesFlags`는 실제로 기록된 월드 상태만 사용한다. 한 번 해결한 사건은 다시 제시하지 않는다.
- 메인 사건은 날짜 고정이며 출현에 운을 요구하지 않는다. 일차당 해결 사건 수는 여전히 2개이며 14일 종료는 유지한다.
- 초기에 탐사 후보가 4개인 날도 있지만 이후 사정에 따라 후보 개수는 달라진다. 현재 무작위 사건 추첨은 하지 않는다.
- 기존 저장 파일에는 `selectedExploration` 필드가 없어도 이전의 기본 탐사로 이어진다. 새 저장에는 고른 탐사 ID를 보존하여 새로고침 뒤 다른 사건으로 바뀌지 않는다.

## 선택이 실제로 달라지는 예시

| 먼저 한 행동 | 이후에 실제로 바뀌는 내용 |
| --- | --- |
| 1일차 조위 표식에서 마른 통로를 확인 | 같은 날 제7창고에서 전력 소모가 적고 구조 성공이 확정된 별도 경로가 열림 |
| 제7창고에서 류를 구함 | 2일차 류의 후속 탐사 등장; 소금 시장에서 류의 배선 지도를 이용한 별도 해결책 열림 |
| 창고의 신호만 남겼거나 구조에 실패 | 2일차 구조대와 재조사하는 후속 탐사 등장; 구조 성공 시 `ryu_safe` 기록 |
| 시장 전력 복구 | 3일차 시장의 자립을 돕거나 정전의 다른 원인을 추적하는 후속 탐사 등장 |
| 문화구역에서 투사기 회수 | 8일차 공동 휴게소의 특별 탐사 등장 |
| 11일차 원격 해제 절차와 10일차 압력 조절기 준비 | 14일차 중앙실에서 **준비한 장비를 사용하는 별도 행동과 엔딩** 해금 |

위 사건은 현재 작성된 예시 연결 고리다. 아직 모든 분기와 플래그가 동일한 밀도로 연결된 것은 아니다.

## 성격과 기록

- 강제 명령 사용 뒤 남는 안정도 감소가 이후 자율성 갈등 계산에 반영된다. 단순 장식 숫자에서 최소한의 인과를 갖는 상태로 수정했다.
- 거부 순간에는 가장 큰 성격 갈등에 맞춘 사유를 보여 주도록 변경했다. 범용 문구가 사건 고유의 뉘앙스를 덮지 않도록 후속 검수가 필요하다.
- 일기는 그날의 실제 결과 사실을 바탕으로 사건별 회고와 거부·강제 개입에 관한 생각을 조합한다. 완전한 자연어 생성이나 자유 입력 과거 설정의 이해는 제공하지 않는다.
- 엔딩은 마지막 결정의 종류를 유지하지만, 구해낸 인물·복구한 시장·함께 본 영상·강제 명령의 흔적 등 누적 기록에 대한 짧은 후일담을 덧붙인다.

## 테스트 및 배포 메모

`tests/engine.test.mjs`는 선택 가능한 탐사, 선택 이후 열린 길, 구조한 NPC의 후속 도움, 잠긴 선택지의 오용, 안정도 연계를 검증한다. 브라우저 스모크 스크립트는 새 출발 버튼에 맞게 수정했다.

코드 내부에서 엔진/콘텐츠를 평가하는 별도 JS 검증으로 15개 엔진 테스트와 기본 경로 200개 시드의 14일 완주를 확인했다. **로컬 Node의 실제 `npm test`, Chromium 브라우저 E2E 및 실제 휴대폰 플레이는 이 작업 환경에서 실행하지 못했다.** 따라서 UI 동작이나 읽는 재미까지 검증 완료했다고 주장하지 않는다.

## 다음 제작 단계

- 하루에 여러 선택 가능한 탐사와 시간/위험의 실질적 교환관계 추가.
- 기억·장비·NPC 신뢰도가 각 사건의 성공률/행동 묘사/대체 선택을 더 폭넓게 변경하도록 확장.
- 사건의 주관적 텍스트를 캐릭터 성향과 이전 결과별로 직접 집필한 스크립트로 보강.
- 단순 고정 진행 수치를 실제 서브 스토리/엔딩의 조건에 활용하고, 플레이어가 얻은 단서에 따른 메인 장면 변주 확대.
- 실물 Android Chrome/삼성 인터넷에서 터치 흐름과 저장·복원 검증.

이 브랜치는 사용자가 직접 플레이한 뒤 `main`에 병합할지 결정하는 용도다. 자동 배포 및 기존 저장 덮어쓰기를 수행하지 않는다.
